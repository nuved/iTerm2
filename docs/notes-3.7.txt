Version TBD (unreleased; built off master)

New Features:
- Quick Look on a web link can use the built-in
  browser, so sites you sign in to stay signed
  in. It can also open when you hover over a
  link (or hold ⌘ while hovering), for domains
  you list. Set this up in Settings > Pointer >
  Preview links on hover > Configure…, or add
  a domain when iTerm2 offers to after you rest
  on one of its links.

Improvements:
- Tab groups look quieter in the Minimal theme.
  A group’s name sits in a small tinted capsule
  instead of a solid full-height block, and a
  thin strip in the group’s color runs under its
  tabs. A collapsed group shows its tab count in
  a badge.
- Downloading and uploading files with scp and
  the SSH integration now read your ssh config
  the way ssh does, including Include and Match
  lines, so hosts set up by tools like Lima
  resolve correctly. Match exec blocks never
  apply, because iTerm2 won’t run commands from
  your config. Issue 13219.
- You can now choose the colors of session
  statuses, such as Claude Code’s “working”,
  “waiting”, and “idle”. In the Session Status
  tool’s settings, each priority pattern has a
  Dot and a Text color well. Leave a well empty
  to keep the color the program chose. Issue
  13130.
- Saved window state takes much less disk space
  for sessions with long scrollback history, so
  restoring windows at launch is faster. Issue
  9360.
- Switching away from iTerm2 no longer stalls
  as long when you have many sessions or long
  scrollback with Shell Integration. Saving
  window state for restoration now skips what
  hasn’t changed and writes less to disk.

Bug Fixes:
- When a program turned on light/dark mode
  change reports and exited without turning
  them off, text like 997;1n appeared at the
  prompt each time you switched between light
  and dark mode. iTerm2 now offers to turn the
  reports off, and turns them off when shell
  integration sees the host change. Issue
  13228.
- A floating Session Note could be drawn behind
  the Clippings panel. It now stays on top.
- Saving settings to a custom folder and Export
  All Settings and Data failed if any profile
  had a hotkey of Control-Space recorded, even a
  disabled one. Fixed.
- With Find open, clicking a command in the
  terminal no longer scrolls the view to the
  first match in that command.
- Double-click selection now finds a match for
  the “Characters considered part of a word”
  regular expression when it continues onto the
  next line of soft-wrapped text.
- Fix crashes and hangs caused by certain control
  sequences and inline images with very large
  counts or sizes. A program’s output could
  crash iTerm2 or freeze its window. Sequences
  that move the cursor, insert, delete, or erase
  characters or lines, or fill or erase a
  rectangle now stop at the edge of the screen
  as they do for smaller counts.
- The control sequence that deletes characters
  now deletes the one under the cursor when the
  cursor has been moved to the last column, and
  the one that copies a rectangle puts the copy
  at the requested row and column instead of
  swapping them.
- Toasts, Global Search, Instant Replay,
  autocomplete popups, and the About window now
  follow the theme: light under the Light
  themes, dark under the Dark themes, and under
  the Minimal theme, light or dark to match the
  current session’s background color. Toasts
  used to always be dark.
- If iTerm2 ran out of file descriptors, the
  Python API stopped accepting connections until
  you restarted it. Also, AI agent hooks no
  longer open connections that iTerm2 will reject
  when a busy Mac is slow to check their
  permission. Issue 13230.
- Checkmarks in the Captured Output tool are
  now kept when windows are restored.
- Double-clicking a line in the Captured Output
  tool did nothing when the Capture Output
  trigger’s command used session variables.
- Two advanced settings refine paragraph
  direction detection for terminal use, where
  a prompt or an English label often precedes
  right-to-left text. Each sets a minimum
  number of right-to-left words: one for lines
  that start with a Latin word (0 never flips
  them; 5 flips a prompt followed by five
  Persian words), one for lines that start
  with a right-to-left word (0 or 1 keeps them
  right-to-left as before; a higher value keeps
  a mostly English line that opens with one
  Persian word left-to-right). Both default to
  0, which is plain first-strong detection. The
  four direction settings share an “RTL
  direction” prefix so they sit together in the
  Advanced settings list, and each description
  shows sample lines per value.
- The glyph rasterizer now clears its whole
  bitmap between glyphs instead of only the
  glyph’s nominal frame, so cursive or
  wide-ligature ink that overflows the frame no
  longer bleeds into the next glyph or trips
  the debug overflow check.
- Right-to-left text no longer flashes
  unreordered for a frame while a program
  that uses synchronized updates (such as
  Claude Code) repaints the screen.
- A new advanced setting, “RTL direction:
  reorder each table cell or pane on its
  own?”, keeps tables and side-by-side panes
  drawn with box-drawing lines intact when
  they hold right-to-left text. Each cell is
  reordered by itself and stays under its
  borders. Off by default.
